## 📖 Overview

VEXO-Commerce is a production-ready e-commerce platform featuring:

- 🔐 JWT Authentication
- 👤 User Accounts
- 🛍 Product Catalog
- 🗂 Categories
- ❤️ Wishlist
- 🛒 Shopping Cart
- 📦 Order Management
- 🎫 Coupon System
- ⭐ Product Reviews
- 🔍 Search & Filtering
- 📊 Admin Dashboard
- 📱 Responsive UI

The backend is powered by **FastAPI**, while the frontend uses **Jinja2 templates** with a premium React-inspired interface.

# 🚀 Installation

Clone the repository

```bash
git clone https://github.com/Vikki-2006/VEXO-Commerce.git
```

Go to project

```bash
cd VEXO-Commerce
```

Install dependencies

```bash
pip install -r requirements.txt
```

Configure environment

```env
DATABASE_URL=
JWT_SECRET=
PORT=
```

Run server

```bash
python main.py
```

or

```bash
uvicorn app.main:app --reload
```
